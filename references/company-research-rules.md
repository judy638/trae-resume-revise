# 公司调研数据采集与展示规范

用于求职策略建议书（Tab 导航结构）中 Tab 03 "目标公司调研" 和 Tab 04 "产品口碑与市场" 的数据采集与展示。

## 数据采集流程

### 0. 天眼查 MCP 授权检查（首次使用必须执行）

在公司调研开始前，必须先检查天眼查 MCP 授权状态：

1. 调用 `RequestAuthorization`，参数：
   - service: `trae-remote-official:tianyancha::tianyancha`
   - scopes: `[]`（空数组表示请求默认权限）
2. 根据授权结果分流：

| 授权结果 | 后续动作 |
|---------|---------|
| **成功** | 进入步骤 1（天眼查 MCP 数据采集） |
| **用户拒绝** | 告知用户"天眼查未授权，将使用公开网络搜索，数据精度可能降低"，进入步骤 3（WebSearch 降级模式） |
| **失败** | 同上，降级为 WebSearch 模式 |

**注意**：
- 已授权用户无需重复授权，可直接调用天眼查 MCP 工具
- 授权是一次性的，后续会话中无需再次请求
- 即使天眼查可用，步骤 2（互联网公开数据采集）仍然执行，用于交叉验证

### 1. 天眼查 MCP 数据采集（授权后执行）

按以下顺序调用天眼查 MCP 工具：

| 步骤 | 工具 | 参数 | 获取内容 |
|------|------|------|----------|
| 1 | `searchCompany` | 公司全称 | companyId |
| 2 | `getCompanyBaseInfo` | companyId | 工商信息：全称、法人、注册资本、成立日期、行业、注册地址、经营范围、社保人数 |
| 3 | `getCompanyShareholders` | companyId | 股东结构、持股比例 |
| 4 | `getCompanyRisk` | companyId | 风险：失信被执行人、行政处罚、经营异常、司法案件 |
| 5 | `getCompanyIpcInfo` | companyId | 知识产权：商标数量、专利、软著 |
| 6 | `getCompanyQualification` | companyId | 资质证书与许可 |
| 7 | `getCompanyRelation` | companyId | 关联企业网络 |

**MCP 工具调用规范**：
- 调用前必须先 LS 工具目录确认工具存在
- 调用前必须 Read 工具的 JSON 描述文件确认参数
- 通过 `run_mcp` 调用，参数放在 `args` 字段内

### 2. 互联网公开数据采集（辅助，始终执行）

通过 WebSearch 并行搜索：

| 搜索关键词模板 | 用途 |
|---------------|------|
| `"{公司名}" BOSS直聘 招聘 薪资 2025 2026` | 在招岗位与薪资 |
| `"{公司名}" 职友集 评价 工资` | 员工评价 |
| `"{公司名}" 小红书 避雷` | 口碑风险 |
| `"{公司名}" 小红书 面试` | 面试经验 |
| `"{品牌名}" 淘宝 销量 评价` | 产品口碑 |
| `"{公司名}" 融资 新闻` | 融资动态 |

### 3. WebSearch 降级模式（天眼查未授权时执行）

当天眼查 MCP 不可用时，通过以下方式获取工商数据：

| 搜索关键词 | 目标 | 数据来源 |
|-----------|------|---------|
| `"{公司名}" 启信宝 工商信息 社保人数` | 工商基本信息 | 启信宝公开页面 |
| `"{公司名}" 天眼查 股东 风险` | 股权与风险 | 天眼查公开页面 |
| `"{统一信用代码}"` | 精确工商匹配 | 国家信用信息系统 |
| `"{公司名}" 行政处罚 失信 经营异常` | 风险信息 | 信用中国等 |

**WebFetch 抓取策略**：
- 优先抓取启信宝公开页面（工商信息较全）
- 天眼查公开页面部分信息需登录，抓取可见部分
- BOSS直聘岗位页面可直接抓取

**降级模式数据标注**：
- 在报告 Tab 03 底部标注"数据来源：公开网络搜索，未经天眼查 MCP 验证"
- 启信宝数据标注"来源：启信宝官方工商数据"

### 4. 链接生成

| 链接类型 | URL 模板 |
|---------|---------|
| 高德地图 | `https://uri.amap.com/search?query={完整地址}` |
| 小红书搜索 | `https://www.xiaohongshu.com/search_result?keyword={URL编码关键词}` |
| 淘宝搜索 | `https://s.taobao.com/search?q={URL编码品牌名}` |

## 展示格式规范

### Tab 03: 目标公司调研

**子章节结构：**

```
03.1 公司基本信息卡
  - 公司全称、法定代表人、注册资本、成立日期
  - 行业分类、注册地址（附高德地图链接）、经营范围
  - 社保缴纳人数（核心数据，加粗展示）
  - 官网链接

03.2 股权结构
  - 股东信息表（股东名称、持股比例、认缴出资额）

03.3 知识产权
  - 商标、专利、软著数量统计

03.4 关联企业
  - 关联企业名称、关系、注册资本

03.5 招聘与薪资
  - BOSS直聘在招岗位列表（岗位名称、薪资范围、链接）
  - 数据真实性对比：社保人数 vs BOSS自报规模
```

**HTML 要求：**
- 基本信息用 `.info-card` 卡片展示
- 表格数据用 `table` 展示
- 所有外部链接 `target="_blank" rel="noopener"`
- 地图链接用按钮样式突出

### Tab 04: 产品口碑与市场

**子章节结构：**

```
04.1 品牌/产品矩阵
  - 品牌名称、产品线、渠道
  - 淘宝/京东搜索链接

04.2 线上口碑
  - 小红书搜索链接（公司+避雷、公司+面试、品牌+评价）

04.3 办公地点
  - 注册地址 + 高德地图链接
```

### 数据真实性原则

- 社保缴纳人数优先于 BOSS 自报规模
- 自报营收必须标注"未经独立验证"
- 无法在工商系统找到的集团主体，标注"可能为关联企业统称"
- 缺少基层员工真实反馈时，需标注
- 天眼查数据与 WebSearch 数据冲突时，以天眼查官方数据为准
- 降级模式获取的数据，需在报告中标注数据来源
